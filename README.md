## 九州賞楓之旅｜Misha 的旅行手帖

2026/11/28–12/03，六天五夜、4 位成人的九州自駕旅遊網頁。

### 網頁功能

- 明亮配色、清晰字體與手機版排版。
- 6 天行程切換、時間軸、景點地圖連結。
- 第 2 天彈性景點、第 3 天高千穗划船 A／B 方案。
- 航班、住宿、租車、旅行費用與四人分攤。
- 26 項行前清單及旅行筆記，保存在目前瀏覽器，不跨裝置同步。

### 檔案

| 檔案 | 用途 |
| --- | --- |
| `index.html` | 網站首頁、航班與固定內容 |
| `style.css` | 明亮配色、字體與手機版排版 |
| `data.js` | 每日行程、住宿、行前清單 |
| `app.js` | 行程切換、方案切換、勾選與筆記 |
| `assets/maple.svg` | 網站圖示 |
| `.nojekyll` | 靜態網站相容設定 |

### 預覽與修改

這是純 HTML、CSS、JavaScript 網站，不需要安裝套件或執行建置。下載檔案後可直接用瀏覽器開啟 `index.html`。修改行程請編輯 `data.js`，調整外觀請編輯 `style.css`。

檔案已放在儲存庫根目錄，方便交由靜態網站服務部署。上傳原始碼不代表已啟用 GitHub Pages；儲存庫仍保留私人設定。

### 資料版本

依 2026/10/20 更新的旅行手冊整理。行程時間為規劃，航班、營業、票價、預約及交通狀況以官方公告與實際訂單為準。地圖按鈕以地點名稱搜尋，出發前請核對入口與門市地址。
